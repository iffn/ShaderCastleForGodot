# Shader Castle for Godot
A museum like experience for learning shaders in Godot.
Made in Godot 4.7.stable

## How to use
### Requirements
CharacterControllerForGodot: https://github.com/iffn/CharacterControllerForGodot

### How to use
- Download Godot 4.7.stable or a compatible version
- Create a new Forward+ project and open it
- Add all requirements to the project
- Add this repository to the root folder of the project
- Open ShaderCastle.tscn
- Run it
